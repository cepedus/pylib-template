# Reference

Reference material is the technical description: accurate, complete, and
neutral. It serves a working reader looking something up — it doesn't care
what they're trying to accomplish.

**Rules for this folder**
- Structure mirrors the thing being described. If the code has
  `module.submodule.Class`, the reference docs should have the same shape.
- No opinions, no narrative, no "you should." State facts.
- Completeness matters more than approachability here — that's what
  tutorials and how-to guides are for.
- If a page starts explaining *why* something is the way it is, that
  content belongs in `docs/explanation/` instead.

Full treatment of this mode: [diataxis.fr/reference](https://diataxis.fr/reference/)
