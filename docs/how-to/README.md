# How-To Guides

A how-to guide is a recipe for a real-world goal, aimed at someone already
competent who is at work, not studying. It assumes the reader can adapt the
steps to their situation.

**Rules for this folder**
- Start from the goal, not from a concept. Title format: "How to `<do the
  specific thing>`."
- Assume competence — don't re-explain fundamentals a working user of this
  project already has.
- Stay on task. If a digression into "why" is needed, link to
  `docs/explanation/` instead of inlining it.
- Cover the realistic variations, not every theoretical one.

Full treatment of this mode: [diataxis.fr/how-to-guides](https://diataxis.fr/how-to-guides/)
