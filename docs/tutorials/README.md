# Tutorials

A tutorial is a lesson: it takes a newcomer through a real, hands-on
experience and guarantees they end up somewhere that works, if they follow
it exactly. The reader is learning, not yet working — the goal is a
successful first experience and the confidence that comes from it, not
efficiency.

**Rules for this folder**
- Every step must be concrete and immediately actionable — no "configure it
  appropriately."
- Guarantee the outcome. If a step depends on something outside the
  tutorial's control, say so and give a fallback.
- Explain as little as possible inline. A one-line reason ("we use HTTPS
  here because it's the default for this platform") is fine; anything
  longer belongs in `docs/explanation/` with a link.
- Don't assume prior knowledge the tutorial hasn't already given the
  reader.
